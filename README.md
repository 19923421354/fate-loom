# 🧵 命运织机（Fate Loom）

> 沉浸式 AI 故事聊天客户端 · 支持自定义 OpenAI 兼容 API

「命运织机」是一个运行在 Android 上的沉浸式 AI 故事叙述客户端。你扮演故事中的角色，AI 负责叙述世界、驱动 NPC，共同编织属于你的命运之线。所有 AI 对话均通过你自己配置的 API 完成，数据完全保存在本地。

## ✨ 功能特性

- 🎭 **沉浸式叙事**：内置专业叙事系统提示词，AI 扮演叙述者与 NPC，玩家完全掌控自己的角色
- 🌍 **六大场景预设**：奇幻、科幻、武侠、悬疑、古言、侦探，一键切换
- 🔌 **自定义 API**：支持任意 OpenAI 兼容接口（DeepSeek / 豆包 / 通义千问 / 智谱 / 硅基流动 / OpenAI…）
- 💬 **流式输出**：实时流式生成，打字机式呈现
- 📚 **多会话管理**：新建、重命名、置顶、归档、搜索、统计、删除
- ✏️ **消息编辑**：修改任意消息、删除、收藏、添加反应、从这里分支重写
- 🔀 **分支叙事**：从任意消息重新开始，保留之前的所有剧情
- 📂 **导入导出**：一键导出对话为 Markdown 文件、完整数据备份/恢复（JSON 文件导入导出）
- 🔍 **会话搜索**：按标题或内容实时过滤会话
- ⏹ **停止生成**：生成过程中可随时中断，不再卡死
- 📊 **统计升级**：查看会话消息数、字数与 Token 估算
- 🧪 **连接测试**：设置页一键检测 API 连通性
- 🔄 **自动检查更新**：启动时自动检查 GitHub 最新版本，发现新版本一键前往下载
- 🐛 **兼容修复**：支持旧版 WebView（AbortController/流式降级），对话更稳定
- 🎨 **Markdown 增强**：任务列表、引用块、图片点击放大、链接新窗口打开
- 📖 **帮助命令**：`/帮助` 查看全部快捷指令
- 🌓 **深色/浅色主题** + 字体大小调节 + 自动滚动 + 回车发送 + TTS 朗读
- ❤️ **赞助开发者**：应用内直接扫码支持（支付宝/微信）

## 📥 安装

直接下载 `织机_v1.2.0.apk` 安装到 Android 7.0+ 设备即可。

> 首次打开后请先进入「设置」配置 API 地址、密钥与模型名称，即可开始创作。

## ⚙️ 快速开始

1. 打开应用，进入「设置」
2. 选择 API 预设（或选择「自定义」手动填写）
3. 填入 API 密钥（可在对应平台官网申请）
4. 点击「聊天」返回，输入你的第一个行动，故事开始！

## 🛠️ 从源码构建 APK

项目采用「HTML 单文件应用 + Android 壳」架构：

```
命运织机/
├── index.html              # 应用全部源码（UI + 逻辑，单文件）
├── manifest.json           # PWA 配置
├── AndroidManifest.xml     # Android 壳 Manifest
├── build120.py             # APK 构建脚本（aapt2 + jarsigner）
└── README.md
```

构建依赖：

- Android SDK（aapt2 / android.jar，platform 23）
- JDK（jarsigner）
- Python 3

```bash
# 1. 准备壳 APK（含 classes.dex，包名 com.aichat.app）
#    将任意兼容壳 APK 放到 build/ 目录并命名为 命运织机_v5.apk

# 2. 执行构建
python3 build120.py

# 3. 产物输出到工作区
#   织机_v1.2.0.apk
```

## 🔐 隐私说明

- 所有对话数据仅保存在本机（localStorage）
- API 密钥仅保存在本机，不会上传任何服务器
- 应用不含任何第三方统计与广告 SDK
